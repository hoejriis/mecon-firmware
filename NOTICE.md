# Licensing and provenance

The public mecon-firmware documentation and MECON additions use MIT, continuing the project's established firmware licence. The [licence file](LICENSE) retains the MeshCore upstream notice and identifies MECON authorship separately.

This repository currently contains documentation and target contracts, not a copy of the firmware implementation. When source is published, preserve upstream MeshCore attribution, applicable file notices and the provenance of every imported component. Third-party components retain their own licences; the root licence does not replace them.

The public refounding uses a pinned released MeshCore baseline and reviewed source/provenance. Private implementation history is not to be published wholesale.

[MeshContinuum](https://github.com/hoejriis/MeshContinuum), the Backend/Reader sister project, uses Apache-2.0 separately.
