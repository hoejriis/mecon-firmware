# Security reporting

Supported releases and the boards and roles each supports are listed in its [release notes](https://github.com/hoejriis/mecon-firmware/releases).

Do not publish suspected vulnerabilities, exploit details, private keys, tokens, passwords or private message contents in public issues.

Report privately through this repository's **Security → Advisories → Report a vulnerability**. If you cannot use it, open a public issue asking only for a private security contact, without any vulnerability details.

A private report should identify the affected build, component or board/role, reproduction conditions and likely impact. A roadmap or contract is not evidence of a completed security review.

See [security postures](docs/STANDALONE_POSTURES.md), the [security model](docs/SECURITY_MODEL.md) and [management authority](docs/contract/AUTHORITY.md) for the device's security boundaries.
